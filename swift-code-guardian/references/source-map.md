# Swift Source Map

Use these official Swift sources as entry points. Prefer current pages from `swift.org` and `docs.swift.org`; if a page requires JavaScript, use web search restricted to those domains and cite the official URL.

## Core Documentation

- Swift documentation root: https://www.swift.org/documentation/
- The Swift Programming Language: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/
- API Design Guidelines: https://www.swift.org/documentation/api-design-guidelines/
- Standard Library: https://developer.apple.com/documentation/swift
- Core Libraries: https://www.swift.org/documentation/core-libraries/
- About Swift: https://www.swift.org/about/

## Concurrency and Migration

- Complete concurrency checking: https://www.swift.org/documentation/concurrency/
- Swift 6 concurrency migration guide: https://www.swift.org/migration/documentation/swift-6-concurrency-migration-guide/
- Data-race safety: https://www.swift.org/migration/documentation/swift-6-concurrency-migration-guide/enabledataracesafety/

## Packages and Tooling

- Swift Package Manager: https://www.swift.org/documentation/package-manager/
- SwiftPM docs: https://docs.swift.org/swiftpm/documentation/packagemanagerdocs/
- DocC: https://www.swift.org/documentation/docc/
- Swift.org install/toolchain info: https://www.swift.org/install/

## Language Evolution and Project Sources

- Swift Evolution: https://www.swift.org/swift-evolution/
- Swift Evolution proposals: https://github.com/swiftlang/swift-evolution
- Swift source repositories: https://www.swift.org/source-code/

## Topic Search Patterns

Use targeted official-source searches such as:

- `site:swift.org/documentation/api-design-guidelines argument labels Swift`
- `site:docs.swift.org/swift-book actor isolation Sendable Swift`
- `site:swift.org/migration Swift 6 concurrency Sendable`
- `site:docs.swift.org/swiftpm Package.swift target dependency`
- `site:developer.apple.com/documentation/swift <StandardLibraryType>`
